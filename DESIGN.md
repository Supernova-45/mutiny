# mutiny design

The normal/mutant structural comparison leads; explanations live in the evidence drawer. Visible text must identify biology, evidence, measurements, or a meaningful action. Do not narrate camera behavior or interface mechanics. Titles ask a concrete cancer-biology question; avoid slogans, italic word emphasis, numbered navigation, oversized metrics, and rounded card layouts.

Warm ivory (#f3f1ec) is the page canvas, charcoal (#252727) the text, copper the response/mutation accent. Molecular stages alone use charcoal (#20272d), lighter semantic atom colors, restrained outlines and desktop ambient occlusion. Coarse-pointer devices use outlines without ambient occlusion. Use DM Sans for navigation and labels, IBM Plex Mono for sequences and measurements. Preserve distinct unresolved-pool and missing-data marks.

The secondary vaccine-study view uses one patient per row on an open canvas, with the target inspector separated by a single rule. The heading is “Which cancer mutations trigger T cells?” The entry page asks “What changes beyond a cancer mutation?” and uses two large synchronized structures, a short prediction/reveal choice, and a mutation → W6 → receptor path. The opening W6 close-up joins matching deposited ring atoms with dashed geometric connectors and pairs the structures with shared-scale RMSD bars. Avoid reintroducing a finding/note box. Local comparisons keep the same paired view and add a residue-wise difference figure. Personalization means visitor predictions and saved views, without inventing patient-specific outcomes. Mobile stacks the structures. Camera movement must never suggest molecular dynamics or an interpolated experimental state. Automatic rotation is opt-in; expanded mode exits with Escape.

Source guidance: [Impeccable](https://github.com/pbakaus/impeccable), particularly distill and craft-floor. Scientific constraints remain in docs/SCIENCE.md.

Camera changes use a short user-triggered transition; reference opacity and measurement bars may animate, never atom coordinates. Pointer interaction interrupts camera motion. Reduced-motion preference disables transitions. Keep source code formatted for readers.

The navigation contains Compare structures, Vaccine study and Candidate review. Structural pages put case selection and the immersive 3D action on one row, with file operations in Save & open. The figure comes before the prediction/reveal. Binding experiment in the mechanism path moves to the experimental question, including when exiting expanded mode. The dark molecular control strip belongs to the 3D figure; evidence stays on paper. Methods follow the current structural or vaccine-study context. Keep W6 measurements without a decorative heading. On phones, receptor selection uses the mechanism path instead of a duplicate toggle.
