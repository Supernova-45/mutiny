## Main limitations

The cohort is already selected for vaccination; the assay does not assign response class to every target; pooled outcomes are unresolved; the model comparison is exploratory. The HHAT structures are a separate mechanistic case rather than structures from the pancreatic trial. These boundaries are encoded in the application and methods.
